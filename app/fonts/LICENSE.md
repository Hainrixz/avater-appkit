# Fonts vendored in this directory

Two typefaces are bundled with this kit:

- **Satoshi** — display / headings. Designer: Indian Type Foundry.
- **General Sans** — body / UI. Designer: Indian Type Foundry.

Both are distributed by [Fontshare](https://www.fontshare.com) under the
**ITF Free Font License (FFL)**, which permits personal and commercial use
and redistribution as part of a larger work, provided the fonts are not sold
on their own.

Full licence text: https://www.fontshare.com/licenses/itf-ffl

If you fork this kit and ship it commercially, keep this file. You inherit the
same obligation. If you would rather not redistribute the binaries, delete this
directory and swap `app/fonts.ts` for the CDN escape hatch documented there.
